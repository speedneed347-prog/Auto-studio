# FullStack Studio V10 — Phase 1 (Platform Foundation)

*Build Anything. Visually. Without Limits.*

Phase 1 delivers the platform foundation: authenticated dashboard, project management on Cloud Firestore,
a Fastify API, and Render/Firebase deployment config. See `docs/IMPLEMENTATION_STATUS.md` for what is
implemented vs planned. Firebase Storage is not used.

## Structure
```
apps/web          React + Vite + Tailwind + Zustand + TanStack Query + React Router
apps/api          Fastify + firebase-admin (REST /api/v1, /health)
packages/shared-types   Zod schemas + types (project, manifest, roles)
packages/project-model  Initial project builder + manifest migrations
docs/  firestore.rules  firestore.indexes.json  firebase.json  render.yaml  .github/workflows/ci.yml
```

## Setup
Requirements: Node >= 20, pnpm 9 (`corepack enable`).
1. Follow `docs/firebase-setup.md` (Auth + Firestore, rules/index deploy).
2. `pnpm install`
3. Create `apps/web/.env.local` with the `VITE_FIREBASE_*` values and `apps/api/.env`-equivalent exports
   (see `.env.example`). The API reads real environment variables, e.g.:
   `FIREBASE_PROJECT_ID=... FIREBASE_SERVICE_ACCOUNT_JSON='{...}' pnpm --filter @fsv10/api dev`
4. `pnpm build` once (workspace packages compile to `dist`), then `pnpm dev`
   → web http://localhost:5173, API http://localhost:8080 (Vite proxies `/api`).

`pnpm lint` · `pnpm typecheck` · `pnpm test` · `pnpm build` · `pnpm format`

## Deploy: GitHub + Render
1. `git init && git add . && git commit -m "Phase 1" && git branch -M main`, create an empty GitHub repo,
   `git remote add origin <url> && git push -u origin main`.
2. Render → New → **Blueprint** → select the repo (uses `render.yaml`; creates API web service + static site).
3. API env: `CORS_ORIGINS` (your static-site URL, comma-separated), `FIREBASE_PROJECT_ID`,
   `FIREBASE_SERVICE_ACCOUNT_JSON`. Web env: the four `VITE_FIREBASE_*` plus `VITE_API_URL` (API URL).
4. Add the Render web domain to Firebase Auth → Authorized domains. Health check: `/health`.
Note: Render's free tier sleeps idle services (first request is slow) and limits may change.
Commit the `pnpm-lock.yaml` generated by your first install for reproducible builds.

## Environment variables
See `.env.example`. API: `NODE_ENV, PORT, CORS_ORIGINS, FIREBASE_PROJECT_ID, FIREBASE_SERVICE_ACCOUNT_JSON`.
Web: `VITE_FIREBASE_API_KEY, VITE_FIREBASE_AUTH_DOMAIN, VITE_FIREBASE_PROJECT_ID, VITE_FIREBASE_APP_ID, VITE_API_URL`.

## Known limitations
- Generated in an offline sandbox: dependencies were NOT installed, and typecheck, lint, tests and builds
  were NOT run. Expect to fix small issues on first `pnpm install && pnpm build && pnpm test`.
- No pnpm lockfile is included. Google sign-in and Firestore were not exercised against a live Firebase project.
- Only Overview and Project Settings workspaces work; all others are labelled planned.
